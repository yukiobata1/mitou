| B2 | 工場は、高額な製造装置を待たせないために台車を多めに配備してきた（保険としての過剰配備）。証言ではなく費用の非対称から論じる: 製造装置は1台数十億〜数百億円、台車は1台約8万ドル。装置を1時間止める損失に比べて台車は安いので、多めに置くのが合理的**だった**。しかし増車は効かなくなり（B4）、制御で減らせるようになった（B5）ので、合理性が反転した、という順で書く（9/22 審査員批評: 「合理的」で止めると削る動機を自分で否定する）。ストッカは傍証の1文まで | 小幡の見立て（9/22: ストッカも過剰に置かれている印象）。装置価格は公表値の出典を付ける【要出典】。見聞ではなく印象なので「〜と聞いた」「〜を見た」とは書かない | 【推論】 | |
| B3 | 保険料とは、余分に買った台車の代金のこと。1台あたり約8万ドル。先行事例では1,000台のうち200台（1,600万ドル分）が制御の工夫で不要になった。どれだけ余分かを示す数値はこの2割しかない | SMMSO 2024の「200台削減で1,600万ドル節約」からの逆算。原文に単価の記載はない | 【推論】 | |
| B4 | 増やすほど効かなくなる。増車だけでは搬送能力は上がらず、過度の増車は逆に能力を下げる | (1) 吉田正義（アシストテクノロジーズジャパン）、日本機械学会誌 2007年12月。同社の事業は2009年に村田機械側へ譲渡（沿革ページの目視確認が必要）。(2) Hwang & Jang, IJPR 2020 表8: 実工場データで搬送要求が10万件/日を超えると、静的経路は「台数を増やしても要求を満たせない」。(3) ASMC 2020 要旨: 業界標準の最短経路型は「1,000台前後の工場では効かないことが示されている」 | 【確認済み】3出典 | |

## 目的（なにを）

| # | 主張 | 採否 |
|---|---|---|
| P1 | 開発: 装置を待たせない配送水準（各装置への配送時間の裾、Q-time）を守ったまま、必要な台数を最小にする経路選択と台車割当の制御。各車が他の車に与える遅れを、遅らされる側の荷物の価値（行き先の装置の重要度、Q-timeの残り、優先度）で重みづけし、区間ごとの混雑への課金として値付けする（9/22 小幡の指摘で修正: 問いは「最小台数で安定稼働」、重みは「どこへの搬送が遅れるか」） | |
| P2 | 設計上の制約: 経路の計算は決定論的な最短経路探索のまま残し、学習が決めるのは区間の重みだけにする。メーカーの既存の制御に載る形 | |
| P3 | 事業化: 国内の搬送メーカーとの共同開発を通じて、制御アルゴリズムを提供する | |

| C3 | 区間の重みを強化学習で動かす研究（Koo et al., IJPR 2026。触る場所は本提案と同じ） | 差は3点: (1) 重みの根拠が「領域の台数を均等にする」学習で、配送時間や台数に直結しない。本提案は1台増えたとき他の車が受ける遅れ（限界費用）から導く。(2) 粒度が領域（8つ、人手で分割。著者が性能の境界条件と明記）。本提案は区間ごとで分割不要。(3) 理論的な裏付けの有無。Koo自身の結果で、学習した重みは人手の固定重みに110〜130台で負けている（表3） | 【確認済み】（原文。research/koo-ijpr2026-reading-2026-09-22.md） | |
