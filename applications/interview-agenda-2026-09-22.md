# メーカー面談のアジェンダと想定反応

- 作成: 2026-09-22
- 状況: ムラタシステム、camLineとはまだ話していない（9/22 小幡確認）。応募（9/25）には間に合わない。二次審査（11/7・8）までに1回ずつ行うのが目標
- 申請書での書き方: 「応募後に国内搬送メーカーへ面談を申し込む」。話していない内容を書かない
- 注意: OHTのメーカーは**村田機械（ムラテック）クリーンFA事業部**。「ムラタシステム」が別会社を指すなら要確認。2007年の日本機械学会誌の記事（吉田正義、アシストテクノロジーズジャパン）の事業は村田機械側へ譲渡されており、当時の技術者が社内にいる可能性がある
- camLineはMES／ラインコントローラのベンダー（Elisa IndustrIQ傘下）。搬送制御はやっていない。聞く相手としての価値は「工場側の困りごと」と「MESと搬送の境界」

## 面談の目的（優先順）

1. **需要の確認**: 台数を減らせることに、メーカーと工場のどちらが価値を感じるか。減らすと売上が減るのはメーカー側なので、ここが最大の論点
2. **現行方式の確認**: 今の経路制御は静的か動的か。学習ベースは検討したか。DAIMをどう見ているか
3. **入口の確認**: 外部のアルゴリズムを部品として組み込む余地があるか。シミュレータ（AutoMod等）とデータをどこまで出せるか
4. **B2の裏付け**: 台数を決める根拠。「装置を待たせないために多めに置く」は実態か

## A. 村田機械（OHTメーカー）向け

### 事前に送る1枚

- 3行の説明（①の要約）と、公開論文の数値（IJPR 2020 表8: 同じ搬送量を7〜8%少ない台数で）
- 「御社の制御を置き換えるのではなく、区間の重みを供給する部品」という立ち位置を先に示す
- 聞きたいことを3つに絞って書く

### 質問（この順で。前半は答えやすいものから）

1. 工場に納めるOHTの台数は、何を根拠に決めていますか。シミュレーションで決める場合、余裕（安全率）はどの程度見込みますか
2. 稼働後に台数を増やす要望はありますか。増やしても効かない、逆効果になった経験はありますか（2007年の貴社系譜の記事に「過度の増車は逆に搬送能力を低下させる」とあります）
3. 現在の経路選択は、静的な最短経路ですか、渋滞に反応する動的経路ですか。ルールの調整は誰が、どの頻度で行いますか
4. 学習ベースの経路制御（KAIST／DAIMなど）は検討されましたか。導入しない理由があれば教えてください
5. 外部のアルゴリズムを、経路コストの重みとして受け取る仕組みは技術的に可能ですか。制御ソフトのどの層に入りますか
6. 評価に使えるシミュレータやレイアウト・需要データを、NDAのもとで提供いただける可能性はありますか。難しい場合、公開シミュレータでの結果をどこまで信用されますか
7. 台数が減ると御社の売上は減ります。それでも組む理由があるとすれば何ですか（競合が先に日本に入るリスク、保守・ソフト収益への転換、既設工場の増産対応など）
8. 8か月で「御社のシミュレータ上で現行方式と比較」まで行けたら、次の一手として何を期待されますか

### 想定される反応

| 反応 | 確率の見立て | 意味 | 次の手 |
|---|---|---|---|
| 「制御アルゴリズムは中核技術で、外部には出せない。データも出せない」 | 高い | 入口が閉じている | 公開レイアウトで完結する計画を維持。「結果だけ見てもらう」形に切り替える。工場側（ユーザ）から要望が出る経路を探す |
| 「動的経路は既に実装している。学習で何%上乗せできるのか」 | 高い | 数値を求められる | 予備実験の数値と、論文の数値（7〜8%、20%）で答える。自分たちの数値は二次審査までに用意 |
| 「台数を減らす提案は、営業的に受けにくい」 | 中 | 需要の主語が違う | 「増産時にレールを敷き直さず対応できる」（E2）に言い換える。メーカーにとっては既設工場の追加受注の材料 |
| 「デッドロックや安全の保証はどうするのか」 | 中 | 実機導入の壁 | 経路計算は決定論的なまま残す（U5）と説明。学習が触るのは重みだけ |
| 「DAIMは知っている。サムスンで動いている」 | 中 | 相手が競合を意識している | B7の「国内の選択肢」が刺さる。ここが最良の展開 |
| 「面白い。研究開発部門につなぐ」 | 低〜中 | 最良 | 担当者名と次回日程を取る。⑥に「面談実施、技術部門と継続協議中」と書ける |
| 「増車が効かない経験はある。だから台数の上限を設けている」 | 中 | B2・B4の裏付け | 二次審査で「メーカー技術者の証言」として使える。発言の要旨をその場で確認して記録 |

### 面談後に申請書・二次審査資料に書けること

- 面談した事実（日付、部門）
- 相手が言った言葉の要旨（誇張しない。確認を取ったものだけ）
- 開いた入口（データ、シミュレータ、次回）と閉じた入口

## B. camLine（MES／ラインコントローラ）向け

### 目的

搬送制御の話ではなく、工場側の困りごとと、MESから見た搬送の境界を聞く。国内の後工程・200mm工場の顧客を持つので、「搬送は律速か」を工場側の視点で確認できる

### 質問

1. 顧客の工場で、搬送の遅れや渋滞が生産指標（サイクルタイム、装置稼働率、Q-time違反）に出ている例はありますか。それはOHTですか、AGVですか
2. MESから搬送システムに渡す情報（優先度、納期）と、戻ってくる情報（到着予定、遅延）はどこまでありますか。到着時刻の予測精度は課題になっていますか
3. 搬送の台数や制御の調整は、工場とメーカーのどちらが主導しますか
4. 工場が搬送メーカーを変えたり、制御ソフトだけ入れ替えたりする事例はありますか
5. 御社の製品群にあるMaterial Control System相当の機能は、経路や配車をどこまで決めますか

### 想定される反応

| 反応 | 確率 | 次の手 |
|---|---|---|
| 「搬送はうちの範囲外。メーカーに聞いてほしい」 | 高い | 質問2（MESと搬送の境界）だけに絞る。到着予測の精度が課題なら、⑦の「工場向け効果測定」の種になる |
| 「後工程はAGV／AMRが中心で、OHTは少ない」 | 中 | 本提案の対象は前工程のOHT。後工程は将来の拡張と位置づける |
| 「渋滞より装置の故障や段取りの方が効く。搬送は律速ではない」 | 中〜高 | 価値の主語を「台数」に置いたことが正しかったと確認できる。二次審査で「工場側もそう言っている」と使える |
| 「顧客の困りごとは聞けるが、顧客名は出せない」 | 高 | 匿名の要旨で十分 |

## C. 二次審査までの動き方

1. 応募直後（9/26〜）: 村田機械の問い合わせ窓口、または研究室・知人経由で面談を申し込む。学生の研究として申し込む方が通りやすい
2. 10月前半: 面談。前半の質問（1〜4）で終わっても、B2・B4の裏付けが取れれば十分
3. 10月後半: 面談の要旨を⑥の補足資料にまとめる。二次審査の想定問答「メーカーは受け入れるのか」の答えにする
4. 面談が取れなかった場合: 「申し込んだが期間内に実現しなかった」と正直に言う。公開情報（2007年の記事、決算資料）で代替する
