# 提出物と審査の観点 一覧（2026年度下期 未踏アドバンスト）

- 確認日: 2026-09-21
- 出典: [公募要領（2026-07-16版）](official-forms/koubo20260716.pdf) の原文。抽出テキストは [official-forms/koubo20260716-extracted.txt](official-forms/koubo20260716-extracted.txt)。公募ページ https://www.ipa.go.jp/jinzai/mitou/advanced/2026second/koubo.html
- 記法: 「原文」= 公募要領の文言 / 「分析」= こちらの読み

## A. 審査員が見るところ

### A-1. 公式の審査基準（原文）

0. **要件**: 提案者の要件とプロジェクトの要件を満たすか（満たさなければ審査対象外）
1. **未踏性**: 「ITを活用して世の中を変えていけるようなイノベーティブ性をもつプロジェクトであること」
2. **ビジネス発展性または高い社会的意義**: 「ターゲット（対象とする市場、社会課題、またはユーザ）が明確であることに加えて、①ニーズの高さ、規模、優位性等についてビジネスの発展性、あるいは②先導性、発信力等について高い社会的意義が認められること」
3. **開発実現性**: 「保有する技術シーズを核とした製品・サービスの開発機能が明確で、チームでコミットされた役割分担、開発スケジュールや開発予算が整理され、具体的に表現されているなど、開発の実現が期待できること」

審査の流れ: 一次（書面）→ 二次（ヒアリング。提案者自身がプレゼン）→ 外部有識者委員会 → 採択決定 → **採択後に**PMと個別面談でマッチング。応募時にPMを選ぶ欄はない。マッチングが成立しなければ契約されない。

### A-2. 即失格・審査対象外になる条件（原文から）

- 法人としての提案。「提案するプロジェクトの内容が提案者の所属組織の事業内容に密接に関連していて所属組織のビジネスモデルの一つと見受けられる場合」は法人提案と判断されうる
- 提案者が実際の開発作業に従事しない（アドバイザー的な参加は不可）
- 1人が複数の提案に加わる
- 過去の契約・約束（秘密保持、競業避止）による制約がある（→ 誓約書で誓約する内容）
- 詳細資料の記入項目に漏れがある、形式要件を満たさない（「要件を満たしていない場合は、審査対象外とし、失格」）
- 所属、提案者全員の情報、知財、他の助成を意図的に書かない（契約しない・解除の対象）

### A-3. 様式の各項目が、3基準のどれを見ているか

| 様式の項目 | 要領が求める中身（原文の要約） | 見られる基準 |
|---|---|---|
| ⓪ 前回との差異 | 過去応募の年度・題名、改良点 | 要件 |
| ① 背景、目的、目標 | 開発と事業化の**両面**を、**専門家でない人にも分かるように**。**競合の概要と差別化要因もここに書く** | 未踏性、事業性 |
| ② 未踏性の主張、期待効果 | 斬新で独創的なアイディア、**保有する技術シーズの優位性**、成果を使うと何が起きるか | 未踏性 |
| ③ 開発の進め方 | 現状のプロトタイプ、期間中の開発内容、体制とコミットされた役割分担、線表、課題と解決策。「計画の緻密さを確認するため」 | 実現性 |
| ④ 実績と実現性 | **全員**のスキル・経験・受賞歴（URL可）、それが実現にどう寄与するか、未踏の採択歴 | 実現性 |
| ⑤ 事業化の新規性・優位性、ターゲットと規模 | 市場・課題・ユーザ、**ニーズの大きさを具体的に**、競合・類似との比較 | 事業性 |
| ⑥ 事業化の進め方 | ビジネスモデル、期間中の事業化作業、体制、線表、課題と解決策 | 事業性、実現性 |
| ⑦ 終了後の計画 | 成果の出し方（起業、公開等）、人員・経費・売上計画 | 事業性 |
| ⑧ 予算内訳 | 実施費用総額の算出根拠を、全員の稼働計画（期間中の総作業時間）と表で | 実現性 |
| ⑨ 所属企業との差異 | 所属企業の事業・技術とどう異なるか | 要件（法人提案でないこと） |

### A-4. 目的意識として持つべきこと（分析）

1. 読むのは半導体の専門家ではない。①は業界用語を一言で説明し、例え（道路網、カーナビ、信号機）を使う。要領自身が「専門家でない人にもわかるように丁寧に」と求めている。
2. ②で問われるのは「保有する技術シーズ」。アイディアの新しさだけでなく、**チームが今持っている技術**が何かを書く。現状ここが最も薄い（プロトタイプなし）。応募前の最小デモ、または松川・白石の研究実績との接続で埋める。
3. ③と⑥は同じ型（内容、体制、線表、課題と解決策）が**開発と事業化の両方**に要求されている。⑥にも体制と線表が要る。現骨子の⑥は体制が抜けている。
4. 競合は①にも書く指定。現骨子は②に比較表を置いているので、①に要約を入れ、⑤で比較、という配置に直す。
5. 「チームでコミットされた役割分担」が実現性の文言に入っている。各人の固有担当と稼働時間が空欄のままでは、この基準を落とす。
6. 採択率は直近8.3%（206件中17件）。3基準のどれか1つでも空白があると通らない前提で書く。

## C. 予算の計算式（⑧と入力2）

- 原文: 「一律 5,000円/時間・人」「1人当たりの毎月の作業時間は、200時間を超えないように」。対象は作業時間のみ。物品購入等は対象外
- 上限1,600万円（2名以上）= **合計3,200時間**
- 例: 3名 × 8か月なら、1人あたり月133時間で上限に達する。学業・会社と両立できる時間を各人が申告し、それに5,000円を掛ける。時間を盛ると④⑧の「コミットされた役割分担」と矛盾するので、実際に出せる時間で書く
- 免税事業者は税抜き、課税事業者は税込みで記入
