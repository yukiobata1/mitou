# OHT-mini MARL PoC（2026-09-22 夜）

目的: 「理論が報酬を決め、MARLが値を出す」を最小構成で動かし、学習の損失が下がることと、学習した課金が基準（課金なし・固定課金）に対してどうかを見る。numpyだけで動く。

## 環境 `oht_env.py`

- レール網: 上下2本の幹線ループ（一方通行）＋ n_bays 本のイントラベイ・ループ（既定6）。区間36、うち幹線24が制御対象（エージェント）、ベイ12にポート
- 車両: 1車線・追い越し不可。区間の収容数 ＝ 長さ（1単位長に1台）。満杯なら手前で待つ（ブロッキング）
- 需要: ポアソン到着（rate 件/ステップ）。最も近い待機車を割り当て
- 経路: 決定論的な最短経路。辺コスト ＝ 長さ × (1 + toll[区間])
- **エージェント**: 幹線区間ごとに1つ。行動 {−Δ, 0, +Δ} で自区間の課金を動かす。観測6次元（自区間・上流・下流の占有率、自課金、全体負荷、待ち要求数）
- **報酬（共有）**: `externality` ＝ −(ブロックされた車両ステップ ＋ 0.1×走行中の車両ステップ) / 正規化。「他の車に与えた遅れ」を罰する限界費用の形。比較用に `dwell`（Littleの法則の台数×滞留）と `balance`（Koo型の台数均等化）も実装
- 9/22夜の追加: 待機車は退避線に入る（`park_idle`）、全車が3区間連続でブロックされたら崩壊として終了

## 学習 `train_marl.py`

独立DQN＋パラメータ共有（全エージェントが同じQネット、64×64のMLP、手書きAdam）、経験再生、目標ネット、Huber損失、ε-greedy（1.0→0.05）。評価は保留した5つの種で、学習方策 vs 課金なし vs 固定課金1.0。

## 結果

|---|---|---|---|---|

### 9/22夜の結論

- **損失が下がることは v3 で示せた**（単調減少、0.02→0.0003）。学習の仕組み自体は正しく動く
- **学習した課金が基準に勝つことは v2 で示せた**（697 vs 475 vs 679）。ただしその条件では損失が暴れる
- 両立しなかった理由は環境側: 環状レールで、迂回がループの詰まり（デッドロック）を誘発する。実工場の制御はループごとの台数上限で回避しており、これを模さないと高密度で課金が逆効果になる。**これは独立批評（audit）が指摘した「デッドロック回避との衝突」そのもの**で、第2期の実装課題として書ける
- 申請書には v3 の損失曲線と v2 の評価を図3として載せ、「小規模な抽象環境での概念実証。デッドロック回避との統合は第2期」と正直に書く

## 2026-09-24: v2設定の再実行（60台と70台）

- 目的: 申請書の「最短経路を選ぶ方式が70台で運ぶ件数を60台で運べた（14%減）」の評価記録を残す。手元に60台の記録がなかった。
- スクリプト: `run_v2_setting.py`（oht_env.py と train_marl.py は変更しない）。v2の後に入った2つの変更（待機車の退避 park_idle=True、詰まったらエピソード終了）を無効にして、v2と同じ条件に戻す。300エピソード、需要0.6、報酬 externality、lr 5e-4、評価は種100〜104の5つ。
- 結果（配送件数、学習 / 課金なし / 固定課金）:

| 条件 | 出力 | 学習 | 課金なし | 固定課金 |
|---|---|---:|---:|---:|
| 70台（v2の再現確認） | `out_v2_70_check/` | 699.2 | 474.6 | 678.8 |
| 60台 | `out_v2_60/` | 700.0 | 698.0 | 612.4 |
| （参考）9/22のv2、70台 | `out2/` | 696.6 | 474.6 | 678.8 |

- 読み:
  - 70台の再実行は9/22のv2と一致した（課金なしと固定課金は完全一致、学習はほぼ同じ）。再現の手順は正しい。
  - 60台では、課金なし（静的な最短経路）でも698件運べ、学習（700件）と差がない。70台で課金なしが475件に落ちたのは、5つの種のうち2つで詰まったためで、台数を減らすと詰まらなくなる。
  - したがって「学習した方式は60台で、最短経路の70台と同じ件数を運べた」は事実だが、「MARLで必要台数を14%減らした」とは言えない。この網では、台数を減らすこと自体が詰まりを解いており、学習による上積みはまだ示せていない。台数が多すぎると詰まる（トレードオフ）ことの裏付けにはなる。
